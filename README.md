# Billiard And Cafe

Website booking meja billiard dan cafe berbasis PHP dan MySQL.

## Fitur

- Login admin dan user
- Booking meja billiard
- Kelola data meja
- Kelola menu makanan dan minuman
- Upload gambar menu
- Dashboard admin

## Teknologi

- PHP
- MySQL
- phpMyAdmin
- HTML
- CSS
- JavaScript
- XAMPP

## Cara Menjalankan

1. Clone atau download repository ini.
2. Pindahkan folder ke `C:/xampp/htdocs/`.
3. Jalankan Apache dan MySQL di XAMPP.
4. Buka phpMyAdmin.
5. Buat database baru.
6. Import file `database/billiard_cafe_db.sql`.
7. Buka browser:

```text
http://localhost/billiard_and_cafe
